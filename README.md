# AWS Student Builder Group — CHARUSAT

A modern, responsive web application for the AWS Student Builder Group at Charotar University of Science and Technology (CHARUSAT). The project showcases the club’s mission, leadership, founding members, mentors, event highlights, and community presence through a polished, dark-themed landing page.

## Overview

The AWS Student Builder Group is a student-led cloud community at CHARUSAT focused on practical learning, technical collaboration, and AWS ecosystem exposure. This repository contains the active frontend implementation of the club website, along with supporting project documentation and legacy assets.

## Features

- Responsive landing page for desktop and mobile
- Community-focused hero and CTA sections
- Leadership and faculty highlight cards
- Founding team and mentor showcases
- Event and workshop feature sections
- Modern visual design with dark theme and accent gradients
- Modular component-based frontend structure
- Scalable architecture for future expansion and backend integration
