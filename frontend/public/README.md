# Public Assets Directory (`public/`)

This directory contains static assets served directly at the root URL (e.g. `public/logo.png` is accessed at `/logo.png`).

---

## Directory & File Overview

### 1. Branding Assets
- `logo.png` & `branding/logo.png`: The official square AWS Student Builder Group logo (with green border and tech accents).
- `banner.png` & `branding/banner.png`: The wide horizontal CHARUSAT AWS club banner (used in the Footer and event certificates).
- `logo.svg`: Vector format of the official club badge.
- `image.svg`: Legacy vector asset (referenced in FAQ central ripple glow).

### 2. Events Media Folders
- `/public/AWS Roots/`: Photographs and posters from the foundational AWS Roots workshop.
- `/public/Terraform Triumphs/`: Session media for the Terraform Infrastructure-as-Code workshop.
- `/public/The Golden Stack/`: Full-stack cloud architecture event assets.

### 3. Team Member Photos
- `/public/team/`: Portrait photographs of core leads and committee members.
  - Recommended dimensions: 400x400 to 600x600 px.
  - Format: `.png` with transparent or dark background for best visual integration.
